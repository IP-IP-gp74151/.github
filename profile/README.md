<h2>专线的报价为什么总说不清</h2>
<p>问「一条海外独享专线多少钱」，得到的答复往往是「看你要多少带宽、几个 IP」。这不是敷衍，而是专线本身由两个独立变量组成：带宽决定管道粗细，IP 数量决定出口数量。两个变量组合出来的价格区间非常宽，不给参数就没法报实价。</p>
<p>所以正确的问法不是问总价，而是先确定自己的带宽档位和 IP 需求，再让商家按组合报价。下面给出组合判断的方法。</p>

<h2>先算带宽：按峰值还是按均值</h2>
<p>带宽预算最容易犯的错，是按平均使用量买，然后被峰值卡住。实际体验由峰值决定，不是均值。视频上传、直播推流、大文件同步，都会产生远高于均值的瞬时需求。</p>

<h2>再定 IP 数量：从业务隔离单元出发</h2>
<p>IP 数量不该拍脑袋。正确的算法是数「隔离单元」：一个需要独立网络身份的运营主体，算一个单元。一个店铺算一个，一个独立账号算一个，一个需要单独地理位置的业务算一个。单元数就是 IP 数的下限。</p>
<p>上限则取决于增长预期。业务处于扩张期，建议预留一定冗余，避免每隔一个月就要追加配置。冗余不宜过多，闲置地址是纯成本。</p>

<h3>IP 是连续段还是分散段</h3>
<p>连续段便于统一管理，但同段的地址在平台侧关联度更高。分散段关联度低，管理成本高。选择取决于业务是否需要强调彼此独立：需要强隔离的，分散更好；需要集中运维的，连续段更省事。</p>
<h3>带宽与 IP 是不是线性叠加</h3>
<p>不是。多个 IP 共用同一条管道时，总带宽是共享的，不是每条独享。要每条 IP 都有保障带宽，需要商家做带宽切分，这在报价上是另一档价格。这一点必须在合同里写清，否则容易出现「买了十个 IP 实际共抢一条线」的情况。</p>

<h2>组合选择的三种典型配置</h2>
<p>第一种，少 IP 大带宽：适合内容上传密集、账号数量不多的团队。第二种，多 IP 中带宽：适合多店铺并行运营、单店流量不大的场景。第三种，多 IP 分带宽：适合规模较大、需要每条出口都有质量保障的团队，成本最高。</p>
<p>先判断自己落在哪一类，再谈价。类别不清就比价，比出来的数字没有可比性。</p>

<h2>报价之外还要看什么</h2>
<p>看三点。一看是否为真专线，即是否独享链路而非共享出口；二看是否有明确的 SLA，包括可用率承诺与故障响应时限；三看计费口径，超流量怎么算、超并发怎么算、临时升配怎么算。</p>
<p>这三点比单价更能决定长期成本。单价低但超流量费用高的方案，在业务高峰期会变成陷阱。</p>

<h2>常见问答</h2>
<h3>十个 IP 一定要配十条带宽吗</h3>
<p>不必。多数场景下多个 IP 共用一条管道就够用，只有当每条出口都需要独立质量保障时才需要切分带宽，成本会明显上升。</p>
<h3>带宽能不能后期加</h3>
<p>多数可以，但可能涉及重新配置甚至更换链路。签约时确认升配流程与所需时间，避免业务高峰期无法及时扩容。</p>
<h3>为什么同样带宽价格差很多</h3>
<p>链路质量、出口资源、SLA 承诺、是否需要跨区域调配都会影响价格。纯比带宽数字没有意义，要连同质量承诺一起比。</p>
<h3>IP 用不完可以退吗</h3>
<p>多数方案按合同周期计费，中途减配不一定退款。采购时按较保守的数量起订，后续追加通常比减配容易。</p>
